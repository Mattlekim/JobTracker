Tax

Built around the UK tax year — 6 April to 5 April — so April is reading figures off a page, not a fortnight of shoebox archaeology.

One tax year, one set of records

Everything the taxman cares about is kept per tax year: the year's income, its expenses, its receipt photos and the bank statements the figures were read off. The tax page shows any year's totals on its own, and a statement that straddles 5 April is filed into both years it touches, so each year carries all of its own evidence.

Figures that match reality

Income is counted off work actually done and money actually received. A clean that was done still counts even if the job has been cancelled since — cancelling says the house is not being cleaned any more, not that the clean never happened. The calendar, the round's figures and the tax page all count the same way, so no two pages of the app ever disagree about what a month took.

The export

The Export button offers two shapes, for the two ways MTD software wants to be fed:

  • The spreadsheet writes every HMRC self-employment box, every time, zeros included — so each figure sits in the same cell in every export. Point a bridging tool at the cells once and it stays pointed, quarter after quarter.
  • The quarterly CSV is the bare figures as a table — one row per period, every column always present — for MTD software that imports rather than links.

Making Tax Digital, without another subscription

Work Tracker is not HMRC-recognised filing software and does not pretend to be — that road runs through bridging software: a tool from HMRC's compatible-software list that reads figures out of a spreadsheet and files them. Work Tracker's exports are shaped exactly for that, which keeps a free filing route open.

Honest about estimates: where a figure is an estimate, the export says so inside the file itself — because a spreadsheet travels without the page it came from.

Year-end in one file

Any tax year can be saved as a single backup file — its income, expenses, receipts and statements together — from the tax page itself. Hand it to your accountant or keep it with the year's paperwork; see Your Data for how backups work.
